久坐办公健身计划 — 分享包使用说明
=====================================

【这是什么】
一份为长期久坐办公人群设计的科学健身计划网页，含 48 个精选动作
（动画演示）、4 条跟练序列（颈椎3分钟 / 腰背舒缓5分钟 / 全身唤醒8分钟 /
睡前放松6分钟）、语音提示、分步图模式与训练记录。无需安装任何软件。

【怎么用】
1. 把整个文件夹解压到任意位置（手机/电脑都行）
2. 双击 index.html，用浏览器打开即可（Edge / Chrome / Safari / Firefox）
3. 手机上：把压缩包发到手机 → 解压 → 用浏览器打开 index.html
   （iOS 用"文件"应用打开后选浏览器打开；安卓直接用自带浏览器打开）
4. ⚠️ 微信里收到压缩包：务必先保存/解压，再用系统浏览器打开。
   不要在微信内置预览里直接点开 html——微信预览不渲染动画和脚本。

【推荐玩法】
- 首页顶部"★ 跟练模式"：每张卡右上角有动画预览，点图直接开始跟练
- 跟练时默认开语音播报和提示音（可随时关）；支持空格暂停、Esc 退出、
  ←→ 键切换动作；"只看分步图"可切换为逐帧演示
- 疼痛 ≥5/10、出现手麻腿麻 → 立即停止

【局域网共享（同一 WiFi 内免发送）】
在任何一台电脑上，进入解压后的文件夹，运行：
  python -m http.server 8000
然后同一 WiFi 下的设备用浏览器访问：
  http://<这台电脑的IP>:8000
（查看本机 IP：Windows 运行 ipconfig 看 IPv4 地址）

- 全部资源都在本地，不联网也能完整使用
