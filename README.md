# 久坐办公健身计划（Office Fitness Plan）

一份为长期久坐办公人群设计的科学健身计划网页：

- **48 个精选动作**，每个都有 180×180 GIF 动画演示与分步图
- **4 条跟练序列**（语音播报 + 倒计时 + 自动左右侧切换）：
  颈椎 3 分钟 / 腰背舒缓 5 分钟 / 全身唤醒 8 分钟 / 睡前放松 6 分钟
- 每小时微休息、每天 10 分钟、室内 90 分钟、健身房训练日与 12 周进阶
- 完全静态、零依赖、离线可用；训练记录保存在本地浏览器

## 在线使用

通过 GitHub Pages 访问（仓库开启 Pages 后自动部署）：

```
https://<你的用户名>.github.io/office-fitness-plan/
```

本地使用：直接双击 `index.html` 即可，无需任何构建或安装。
